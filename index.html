A ESTRUTURA DO SITE

Código Base

!DOCTYPE HTML

DOCTYPE define o documento como HTML5.

HTML E LANG

Html é uma TAG onde fica todo o código HTML
Lang é um ATRIBUTO para definir a linguagem do site.
Pt-br é o VALOR para definir que a linguagem do site é Português do Brasil
Isso tudo é oque chamamos de ELEMENTO HTML.

HEAD

Head é a área de configurações do site.

META, CHARSET, NAME E CONTENT

Meta é a tag para definir metadados do site
Charset é o atributo que define o conjunto de caracteres
Name e content definem a escala do site na tela da plataforma usada.

TITLE

Define o título que fica na guia do site.

BODY

É aonde fica todos os elementos visíveis que você está vendo no site agora.

COMENTÁRIOS

Use < ! -- -- > para comentar no seu código tudo dentro dessa tag fica invísivel no site

DICA: Quando criar um Documento HTML, digite ! para já criar o código base do documento HTML.

Tags de Imagem

Você sabe oque muda se a imagem ter a extensão jpg ou png??
O JPG ele tem mais poder de compactação, ou seja consegue reduzir o tamanho do arquivo, mas à custa da qualidade da imagem.
Já o PNG ele é o contrário do JPG, ele é mais pesado, mas não perde qualidade da imagem e permite transparência.
E tem também a extensão GIF que permite animação.

VOCÊ SABIA: Você não pode usar qualquer imagem no google com intuito de ganhar dinheiro
Para não usar as imagens erradas faça a pesquisa no google imagens, vá em ferramentas, depois em direito de uso e selecioneLicença Creative Commons
Ou use o site Unsplash ou Pexels mas temvários outros também

DICA: Uma imagem muito grande pode pesar muito seu site, é bom você adicionar imagens de no máximo 1500 de largura e 1000 de altura para ter o equilíbrio de boa qualidade e desempenho. O recomendado é para celular 300x300, para tablets 700x700 e para computadores 1000x1000. Baixe o app Gimp para redimensionar sua imagem e você pode editar sua imagens nele de maneira gratuita

Favicon

Da para add um favicon(icone da guia) usando a tag LINK na parte HEAD do código é só digitar link e antes de apertar enter você seleciona link:favicon, ai você coloca o nome do arquivo do favicon no href

É recomendado você usar um arquivo de imagem .ico para conseguir imagens com e ssa extensão você pode encontrar no site Icon Arquive, você pode criar um no Favicon.cc ou criar um favicon a partir de um png pelo Favicon.io

Imagem Dinâmica

Essa tag é praticamente essencial se quiser fazer um site profissional que faça com que as pessoas não saiam rápido, e por causa que as pessoas não saem do seu site tão rápido o google vai valorizar seu site

Formatos

JPEG: JPEG ou JPG use-os quando precisar de arquivos mais leves e excelente compatibilidade com a maioria dos dispositivos e navegadores.
PNG: O formato de arquivo PNG é amplamente utilizado em sites para exibir imagens digitais de alta qualidade ou sem fundo.
GIF: Eles suportam animação básica.
ICO: Use o formato ICO quando precisar criar ícones para sites.

Vídeos

Vídeos Incorporados Externamente

É recomendado você incorporar sites do youtube porque se você usar vídeos baixados pode pesar no custo da hospedagem, mas o problema do youtube é que o seu vídeo ficará público e dependendo da situação você não irá querer isso, por isso se for o caso use o vimeo, mas o problema dele é que ele é pago mas ele tem qualidade superior ao youtube então você terá que se ajustar conforme a situação

Para incorporar é simples basta ir em compartilhar e selecionar a opção incorporar e copiar o código

Vídeos de Hospedagem Própria

Aqui no caso de baixar os vídeos em hospedagem própria acontece denovo você não pode simplesmente usar qualquer vídeo por conta dos direitos autorais, para fugir disso use o Pexels que eu já recomendei.
E é recomendado você tentar comprimir o arquivo por as vezes estar muito pesado e quanto mais pesado mais custoso será a hospedagem do site. Por isso baixe o HandBrake que é uma ferramenta, software ou equipamento que converte arquivos ou sinais de mídia de um formato para outro.
E uma dica não precisa deixar seu vídeo passar de 1920x1080 e só usar 1080 para quando querer qualidade máxima no geral não precisa ser tão alta a resolução
Para saber qual type pesquise

Da para usar alguns atributos adicionais como o LOOP para o quando vídeo acabar voltar do início

Formatos

MP4: O formato MP4 deve ser a sua escolha principal quando você precisar de um equilíbrio ideal entre alta qualidade de imagem/som e um tamanho de arquivo leve.
MOV: O formato MOV deve ser usado quando você prioriza qualidade de vídeo máxima e trabalha em fluxos de trabalho profissionais.
MKV: O formato MKV é um "contêiner" de mídia ideal quando você precisa armazenar, em um único arquivo, vídeos de altíssima qualidade, múltiplas faixas de áudio, legendas variadas e até mesmo capítulos.

Áudio

Nesse caso para evitar de colocar um áudio com direitos autorais você pode ir no seu perfil do youtube e selecionar YouTube Studio e nele procurar pela biblioteca de áudio, qualquer som que baixar não terá que direitos autorais mas recomendo que filtre para aparecer músicas que não precise atribuir, para não precisar incluir as informações do som

As tags AUDIO e VIDEO funcionam igual a tag PICTURE e elas praticamente se usam da mesma maneira ela é uma tag de condição se a primeira linha dentro de alguma dessas tags não funcionar ela le a proxima e assim por diante.
E uma dica se for colocar uma ordem aleatoria coloque do arquivo mais leve para o mais pesado.

Formatos

MP3: Use o formato MP3 quando precisar de compatibilidade universal e arquivos leves.
OGG: O formato OGG deve ser usado quando você precisa de um arquivo de áudio altamente comprimido com qualidade superior ao MP3 e prefere uma tecnologia de código aberto e livre de royalties.
